# Physics workload lab

Open `physics_workload_lab.tscn` and press F6. Space changes target density;
S saves a native sampler JSON report and displays its path. Inspector controls
counts, scheduled decisions and approximate separation; restart for A/B runs.

The fixture composes existing Nucleus owners, including native character motion
and pathfinding. It is not a game starter or a hardware performance certification.
Read [runtime optimization](../../docs/components/runtime_optimization.md)
for workload boundaries and integration defaults.
